# Harcama Takip Uygulaması

Python ve Microsoft SQL Server kullanılarak geliştirilen kişisel gelir-gider takip uygulaması.

# Proje Hakkında

Harcama Takip Uygulaması, kullanıcıların kişisel gelir ve giderlerini
düzenli bir şekilde takip edebilmelerini ve finansal durumlarını daha
kolay yönetebilmelerini sağlamak amacıyla geliştirilmiş Python tabanlı 
bir konsol uygulamasıdır.

Uygulama sayesinde kullanıcılar sisteme kayıt olabilir, hesaplarına
giriş yapabilir, gelir ve gider işlemlerini farklı kategoriler altında
kaydedebilir ve geçmiş işlemlerini görüntüleyebilir.

Kullanıcılar ayrıca belirli dönemler için bütçe oluşturabilir,
kategorilere göre harcama limitleri belirleyebilir ve yaptıkları
harcamaların bütçeleri üzerindeki etkisini takip edebilir.

Uygulamada bulunan filtreleme ve raporlama özellikleri sayesinde
işlemler tarih, kategori ve işlem türüne göre incelenebilir.
Genel gelir-gider durumu ve kategori bazlı harcama dağılımları
görüntülenerek kullanıcının finansal hareketlerini analiz etmesi
kolaylaştırılır.

Proje, Python programlama dili ve Microsoft SQL Server veritabanı
kullanılarak geliştirilmiştir. Kullanıcı bilgileri ve finansal
işlemler veritabanında saklanarak verilerin düzenli bir şekilde
yönetilmesi amaçlanmıştır.

# Kullanılan Teknolojiler

- Python
- Microsoft SQL Server
- SQL
- pyodbc

# Özellikler

- Kullanıcı kayıt ve giriş işlemleri
- Gelir ve gider ekleme
- Gelir ve giderleri listeleme
- Kategori ekleme ve yönetme
- İşlemleri filtreleme
- Kategori bazlı raporlama
- Genel gelir-gider raporlama
- Bütçe oluşturma ve bütçe kontrolü

# Veritabanı Yönetimi

Uygulamada kullanıcı bilgileri, kategoriler, gelir-gider işlemleri
ve bütçe kayıtları Microsoft SQL Server kullanılarak yönetilmektedir.

# Projenin Amacı

Bu projenin amacı Python programlama dili ve SQL kullanarak
veritabanı bağlantısı, veri yönetimi, CRUD işlemleri,
filtreleme ve raporlama konularında uygulamalı deneyim kazanmaktır.
